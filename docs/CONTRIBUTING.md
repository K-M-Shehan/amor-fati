# Contributing

Guidelines
- Add new levels under `scenes/levels/` and corresponding script under `scripts/` when behaviour is level-specific.
- Add waypoints to the scene and put them in the `waypoints` group for graph generation.
- Follow existing naming for exported variables and groups (`enemies`, `waypoints`, `crates`).

Running tests / manual checks
- Run scenes locally and use the debug visualizer for pathfinding checks.
